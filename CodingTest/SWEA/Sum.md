###  두수의 합경우의수 하기 && 크기도 또한 정해져있음 

N = 최대 크기, sum = 숫자들의 함

if(sum <= N+1) 여기서    
return sum -1; 를해야함? 이유가 뭐임?    
이경우는 (1, sum -1) -> (2, sum-2) ------- (sum-1, 1)의 경우의 수 인거임
N보다 작으니까 sum내부에서 해결이 가능한거지   

------

반대의 경우  SUM > N+1 은 뭐냐??   
N까지 써야 해결이 가능한거야    
(N,1) 이런거 
ex) N = 5  sum = 8이야
(5,3) , (4,4) ,(3,5) 이렇게 되는거지 
이가지수를 어떻게 그럼 리턴할것이냐? 

* (x,y)이라 치면 
* x+y = sum 이어야하는데   
* x = sum -y   
* x <=n   
* sum - y <= N    
* sum - N <= y <= N 이식이 성립함  
* y 가들어가는 경우의 수가 정리되면 자동으로 x도 
* 경우의 수가 정해야지겠지?  
* N - (sum -N) + 1 = 2N - sum + 1;임  

### 너의 의문점이뭐야? 
아래 방법으로는 저게 해결이 안되냐?
당연히 안된다 왜냐
N이 sum보다 작은경우라서 이렇게 정의를한건데
sum보다 큰경우를 가져와서 정의를하면 당연히 개수도안맞겠지요
