# 정수 삼각형 시간복잡도 정리

## 문제 상황

정수 삼각형 문제는 맨 위에서 시작해서 아래로 내려가며 선택한 숫자의 합이 최대가 되는 경로를 찾는 문제다.

각 위치에서는 다음 줄의 두 위치 중 하나로 이동할 수 있다.

```text
현재 위치: triangle[row][col]

이동 가능:
1. 아래       -> triangle[row + 1][col]
2. 오른쪽 아래 -> triangle[row + 1][col + 1]


DFS로 풀었을 때
DFS는 가능한 모든 경로를 끝까지 탐색한다.
높이가 n인 삼각형에서 맨 아래까지 내려가려면 총 n - 1번 선택해야 한다.
각 선택마다 경우의 수가 2개씩 생긴다.


DFS은 재귀를 통해서 2개로 나뉘면서 모든 경로를 탐색해서 2^n이고 
DP은  이중 for문을 통해서 n^2이라서 DP로 가는게 맞다
